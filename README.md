# Al-Raqā'iq (الرقائق) - Pelembut-pelembut Hati (Web-PWA)

Aplikasi Web Progresif (PWA) bagi kitab agung **Al-Raqā'iq (Pelembut-pelembut Hati)** karya Al-Fadhil **As-Syeikh Muhammad Ahmad ar-Rasyid** *rahimahullah*.

Siri Tarbiah & Tazkiyah Fiqh Haraki dalam himpunan *Rasā'il al-'Ayn* (seiring dengan *Al-Muntalaq*, *Al-‘Awā’iq*, dan *Al-Masār*).

---

## 🌟 Ciri-Ciri Utama Aplikasi

- **3 Lapisan Kandungan Lengkap:**
  1. 📖 **Versi Penuh:** 13 Bahagian (Mukadimah, Bab 1-12 & Khatimah al-Bawariq) bersama 82 Subtajuk tematik, 948 perenggan, dan 122 nota kaki ilmiah kanonikal.
  2. ⚡ **Ringkasan & Intisari Ilmiah:** Ringkasan am setiap bab berpandukan falsafah dakwah dan poin-poin teras perjuangan.
  3. 💎 **Intisari Subtopik 4 Tiang Fiqh Haraki & Mutiara Hikmah:** Analisis diagnostik menyeluruh merungkai kelalaian hati, gejala penyelusupan nafsu, implikasi ke atas saf, serta preskripsi penawar salaf.
- **Enjin Carian Pantas:** Mencari perkataan kunci, hadis, kalam tokoh, dan topik dengan penyerlahan kata (*highlighting*).
- **Luar Talian Sepenuhnya (Offline-First):** Dilengkapi Service Worker (`sw.js`) dan Cache Storage untuk pembacaan lancar tanpa sambungan internet.
- **Reka Bentuk Premium & Responsif:** Bertemakan *Emerald Sage & Warm Radiant Gold*, menyokong Mod Gelap (*Dark Mode*) dan Mod Cerah (*Light Mode*), penanda halaman (*bookmarks*), serta kawalan saiz fon.
- **Sedia untuk Cloudflare Pages / GitHub Pages:** Struktur fail serasi 100% untuk di-deploy terus ke Cloudflare Pages atau GitHub Pages.

---

## 🚀 Pemasangan & Penggunaan Tempatan

1. Buka folder ini di komputer anda.
2. Klik dua kali pada fail `buka_pwa.bat` untuk memulakan pelayan tempatan pada `http://localhost:8080`.
